# 최근 5일 의견 반영 — 2026-11-16

Gmail의 최근 5일 베리숲 의견 15건을 확인했다. 동일한 요청은 합쳤고 기능 요청이 없는 기호 메일 1건은 변경 대상에서 제외했다. 개인정보와 원문은 이 문서에 옮기지 않는다.

| 의견 | 반영 내용과 검증 |
| --- | --- |
| 별빛 원정대를 할 수 없음 | 지도 바로가기·진입 조건 안내, 원정 중 위치 충돌 제거. PC·모바일 통과 |
| 새 직업·무기 | 정령술사·별길 연금술사 및 무기 3종 추가 |
| 칭호 효과·새 스킬 | 장착한 획득 칭호 하나의 효과 5~15%, 스킬 13종·3D 효과 추가 |
| 세계 3 | 새벽의 세계수 3개 지역, 순차 탐험·봉인석·수호자·최초 보상·저장 복원 구현 |
| 4차 전직 | 레벨100 실제 허수아비 실습 후 전직, 5직업 지원. PC·모바일 통과 |
| 베리 사용처 부족 | 무기+10·공격스킬+5 확정 강화, 새 무기·베리 풍차 추가 |
| 기호만 있는 의견 | 기능 요청이 없어 코드 변경 없음 |
| 상점을 갈 수 없음 | 원정 중 상점 진입 차단 제거, 복귀 위치 충돌 수정 |
| 길드 | 초대 코드·최대24명·길드장 이전·추방·탈퇴·재접속, 실제 SQL 및 두 브라우저 검사 통과 |
| 베리를 빨리 버는 장치 | 베리 풍차3단계, 학습·사냥 보상+10/20/30%, 실제 활동10회 충전 후 수확 |
| 호수에서 비정상 이동 | 지상 물 진입 차단·착지 구조. PC·모바일 통과 |
| 히든 직업·강화·친구 대전 | 기본3직업 실습+랜턴+기본 사냥숲30회 경로 해금, 강화 확대, 두 기기 실시간5문제 대전 |
| 100마리 이후25% 보상 불편 | 일반 사냥 일일 감액 제거. 낮은 구역·보스 반복 보상 규칙 유지 |
| 움직이지 않음 | 채팅 입력란을 벗어나도 이동 잠금이 남는 오류 수정. 입력·이동 검사 통과 |
| 게임에서 자꾸 나가짐 | 실제 WebGL context loss 시 즉시 저장·가벼운 화면 복구 제공. PC·모바일 강제 손실·복구 검사 통과. 제보 기기와 원인은 확인 불가 |

기존 저장 키와 학습 기록, 교사·복구 코드, 오답/중단 무손실, 즉시 저장을 보존했다. 직업기록 v1/v2를 v3로 이전하며 기존 세계2·보스 기록도 유지한다. 웹·앱 공통198개 소스를 함께 동기화하고 앱 이용권은 별도 유지했다.

검증: 신규 PC·모바일 브라우저20개 사례 통과(길드·대전4개는 화면 갱신 수정 후 재검사 통과). 실제 전투·보상·저장 복원·두 기기 대전·WebGL 손실을 실행했다. 풍차는 실제 사냥1회 충전을 확인한 뒤 준비된 충전10회 기록의 수확을 검사했고, 10회 누적은 단위 검사로 확인했다. 화면 자료는 `test-results-feedback-final/`, `test-results-community-final/`, `test-results-stability/`에 보관한다.

운영 배포와 전체 최종 검사는 진행 중이다. Android/iOS 실기기는 검사하지 않았다.
