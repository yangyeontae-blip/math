# 직업·스킬·가시덩굴 숲

광장 왼쪽 Y자 길에서 위쪽은 가시덩굴 숲, 아래쪽은 상점거리다. E 또는 휴대폰 상호작용 버튼으로 출입하고 각각의 입구 앞으로 돌아온다.

## 직업과 조작

레벨 10에 기사·마법사·궁수를 선택하고 수련 후 1차 전직한다. 레벨 30·60에는 각각 2·3차 전직이 열린다. 직업별 기록과 네 스킬 장착을 보관하며 학교에서 무료로 직업을 바꾼다. 각 직업의 10·30·60레벨 전직 때 새 스킬을 하나씩 더 배워 직업별 7개, 공통 포함 24개가 된다. 기존 전직 캐릭터는 접속할 때 해당 단계 스킬을 추가로 받으며 기존 네 슬롯은 유지한다. 왼쪽 위에 기사→수호기사→고대숲 기사, 마법사→마도사→별빛 현자, 궁수→레인저→폭풍의 궁수 칭호를 표시한다.

기본 공격은 고른 몬스터를 계속 때리고, 그 몬스터 둘레 3.2칸 안의 다른 몬스터도 60% 피해를 받는 광역 공격이다. 좋은 무기일수록 사냥 공격력이 크게 오른다(무기 단계마다 +22%, 강화마다 +15%). 기본 공격은 F 또는 공격 버튼 누르기 유지, 스킬은 1~4 또는 네 버튼이다. 가까운 적을 자동 조준하고 적을 눌러 대상을 변경한다. 사냥 중 시각적으로 하차하고 나올 때 원래 탈것을 복원한다.

| 계열 | 스킬 |
| --- | --- |
| 공통 | 잎새 방패 · 바람 걸음 · 길잡이 등불 |
| 기사 | 초승달 베기 · 방패 돌진 · 뿌리 강타 · 숲의 수호 |
| 마법사 | 별빛 탄환 · 서리꽃 · 불꽃 소용돌이 · 별비 |
| 궁수 | 바람 화살 · 관통 사격 · 덩굴 덫 · 폭풍 화살 |

수련 마당에서 단일·복수·공격하는 허수아비를 고른다. 실제 적중·방어·이동·속박으로 판정하며 체험과 연습에는 재화·경험치를 지급하지 않는다. 모험 기록은 직업·스킬과 수련·사냥 기록으로 나뉜다.

## 사냥과 저장

- 권장 레벨 1·10·30·60 구역에 최대 6마리가 등장한다. 공격을 미리 표시하고 처치 후 12초가 지나도 플레이어 가까이에는 재생성하지 않는다.
- 레벨 기본 공격력은 8 + 레벨×1.15 + √레벨×1.8이며, 무기 단계당 +22%·강화당 +15%를 추가 적용한다. 무기 없는 레벨 1/30/60/100은 약 11/52/91/141의 공격력을 갖는다. 같은 비율로 기본 공격과 공격 스킬이 함께 강해진다. 쓰러지면 손실 없이 야영지에서 회복하고 3초간 보호받는다.
- 기본 보상은 구역별 베리 20/50/100/200, 경험치 12/30/60/120이다(2026-10-28 강화). 권장 레벨보다 20 이상 높으면 10%, 구역별 당일 100마리 이후에는 25%로 줄고 함께 적용하면 곱한 뒤 버린다. 물약은 적용한다.
- 사냥은 학습 정답 수·학습 미션·협동 보스 피해에 포함하지 않는다. 처치·보상·레벨업을 즉시 저장하고 실패 시 알림과 재시도를 제공한다.
- 저장 키를 유지하고 버전 21을 22로 승계한다. 같은 프로필의 별도 학교 기록을 통합하며 내보내기·불러오기에 포함한다. 사냥 중 재접속하면 야영지에서 시작한다.

## 자체 제작 그림과 검증 조건

기존 15개 문양은 `public/art/skill-sigils-v1.webp`의 5×3 그림 시트를 사용한다. 생성 원본은 `docs/art/skill-sigils-source.png`에 보관하고 웹에서는 같은 그림의 가벼운 WebP 사본을 표시한다. 기본 이미지 생성 도구를 사용했으며 제작 요청은 “독자적인 손그림 동화 RPG, 짙은 보석색 배경, 금속 테두리, 잎 방패·바람·등불·검·뿌리·별·서리·불꽃·활·덩굴의 선명한 중심 문양, 글자 없는 정렬된 5×3 게임 UI 아틀라스”다. 다른 게임의 자산을 복제하지 않았다.

합성 저장과 격리된 브라우저로 검사하며 실제 학생 기록과 온라인 순위에 시험 결과를 보내지 않는다. 화면 크기·터치 모의 검사는 실제 휴대폰의 발열·배터리 측정이 아니다. 최종 검사 결과는 출시 시 아래에 기록한다.

## 출시 검증 (2026-10-27)

- 웹: 타입 검사, 320개 단위 검사, 제작 빌드 통과. 보호 동작 검사와 기존 수학·저장·집꾸미기 흐름을 포함한다.
- 앱: 타입 검사, 298개 단위 검사, 제작 빌드와 Android/iOS 공통 웹 자산 동기화 통과. 앱 구매 제한·가명·오프라인 설정을 유지한다.
- 브라우저: PC·390×844에서 기존 흐름과 실제 전직·사냥·즉시 저장·새로고침 야영지 복귀·직업별 장착 복원의 12개 검사 통과. 자동 검사에서는 격리된 합성 저장을 사용한다.
- 네 화면 크기(390×844, 844×390, 768×1024, 1280×900)에서 학교·수련·기록·사냥 화면을 확인했다. 실제 휴대폰 검사가 아닌 Chrome 화면·입력 모의 검사다.
- 렌더러 점검: 네 사냥 구역·15개 효과, 돌진의 얇은 벽 충돌, 세 허수아비 관통, 하차와 복귀를 확인했다. 지역을 12회 왕복한 후 자원은 사냥 77개 지오메트리/10개 텍스처, 광장 527개/10개로 안정됐다. 개발용 검사이며 학생 플레이 횟수로 세지 않는다.
- 배포 자산에는 개발용 문제 정답 처리 도구가 포함되지 않는다. 스킬 그림은 662,774바이트 WebP로 제공한다.

- 추가 동시 터치 검사 1개 통과: 이동 손가락만 해제한 뒤 공격 손가락 유지와 실제 적 체력 감소를 확인했다. 기존 12개와 합쳐 브라우저 동작 13개를 검사했다(PC에서는 터치 전용 항목 제외).

- 앱 제작 화면에서도 네 화면 크기 모두 직업 선택 → 두 스킬 실제 실습 → 전직 → 네 슬롯 → 사냥 보상 → 학습 통계 무변경 → 새로고침 이어하기 → 광장 복귀를 통과했다. 외부 요청·JavaScript/셰이더 오류는 0이며 제작판 개발용 API는 노출되지 않는다.

## 2026-10-28 전설 펫·등급·스타일

- 귀염둥이 뽀짝이: 전설, 150,000베리, 탐색 22칸. 장착 시 뽀짝이의 수호자 칭호와 황금 꽃·발바닥 후광. 살구빛 곱슬털·처진 귀·동그란 눈을 가진 독자적인 푸들 모델이다.
- 실제 장착 시 사냥 공격 +45%, 최대 체력 +35%, 피해 20% 감소, 사냥 베리 +50%·경험치 +40%. 방어는 스킬과 더하지 않고 가장 강한 하나만 적용한다. 수련에는 특전·보상을 적용하지 않는다.
- 일반/레어/희귀/유니크/전설 다섯 등급과 별도 표기 색상. 무기·옷·탈것·펫·물약·가구·정원·헤어·표정의 표시용 분류이며 저장·기존 아이템 능력을 바꾸지 않는다.
