# 새벽서약 스킬 그림

기본 제공 image_gen 도구로 제작한 새 판타지 MMORPG 화풍의 24칸 그림입니다. 기존 게임 아이콘을 복제하거나 외부 이미지를 가져오지 않았습니다. 원본은 1024×1536 PNG이며 같은 픽셀 크기의 WebP로 인코딩해 public/art/skill-sigils-dawn-v1.webp에 보관합니다.

프롬프트는 4열×6행의 정확한 격자, 각 칸을 채우는 짙은 배경과 선명한 중심 형태, 손으로 그린 판타지 마법, 금빛 하이라이트, 글자·숫자·테두리·칸 여백 없음으로 지정했습니다.

칸 순서와 주제는 다음과 같습니다.

1. 대지의 노래: 빛나는 초록 새싹
2. 달빛 씨앗: 은빛 초승달과 씨앗
3. 개화의 고리: 꽃으로 이루어진 원
4. 고대 나무의 숨결: 온화한 나무 정령
5. 세계수의 뿌리: 빛나는 뿌리
6. 반짝 약병: 금빛 약병
7. 서리 이슬병: 푸른 얼음 약병
8. 프리즘 폭발: 무지갯빛 수정
9. 오로라 봉인: 보라색 마법진
10. 별의 연성: 별을 만드는 도가니
11. 여명의 왕관: 태양 왕관과 검
12. 은하 대폭발: 보랏빛 은하
13. 하늘폭풍 사격: 독수리와 폭풍 화살
14. 태양의 서약: 축복받은 태양검
15. 우주의 탄생: 행성 궤도와 우주 구체
16. 천공의 유성우: 은빛 유성 화살
17. 영원의 개화: 생명 에너지의 연꽃
18. 만물의 연성: 우주를 담은 도가니
19. 반짝 음표: 금빛 분홍 음표
20. 꽃잎 화음: 꽃잎과 음악의 원
21. 달빛 소나타: 초승달과 오선보
22. 오로라 찬가: 오로라 음률
23. 별빛 피날레: 금빛 별똥별
24. 별바다 교향곡: 파도와 하프

소비 화면은 스킬 선택·수련·모험 기록·전투 HUD입니다. 연결은 src/skill-art.ts의 고정 ID를 기준으로 하며 새 그림이 없는 기존 스킬의 그림은 유지합니다.
