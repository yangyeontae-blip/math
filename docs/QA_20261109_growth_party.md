# QA 기록 — 2026-11-09 growth-party.1

화면 버전 `2026-11-09.growth-party.1`. 본판(math)과 앱 공통 소스(berryforest)의 같은 공통 세대에서 확인했습니다.

## 출시 전 수정

- **시작 빈 화면(TDZ)**: `mountPlaza` 첫 `render()`가 초기화 전 `world`를 읽어 시작 화면이 비던 문제. `render()`는 더 이상 `world`를 읽지 않고, `sync()`가 확인한 수학숲 여부를 기억해 표시합니다.
- **명예의 전당 진입**: 중앙광장 안내(연태쌤/앱의 베리쌤) 대화에 「🏆 명예의 전당」 버튼이 빠져 있던 문제를 양쪽 `main.ts`에 각각 추가(전체 덮어쓰기 없음). 공통 화면 머리말은 앱 NPC 이름과 충돌하지 않게 「선생님과 함께 보는」으로 통일.
- **운영자 안전 복귀**: 운영자가 잠긴 수학숲 단계를 둘러본 뒤 저장하면, 일반 조건으로 잠긴 단계 대신 광장 복귀 위치를 저장합니다(완료 기록은 만들지 않음). 단위 테스트 추가.
- **공통 서버 파일**: `realtime/index.mjs`가 불러오는 `realtime/hall.mjs`, `realtime/party.mjs`(및 `party.test.mjs`)를 공통 목록에 추가해 앱 저장소에도 동기화.

## 브라우저 검사 (Playwright, 격리 프로필의 설치형 Chrome, PC·모바일 모의)

- 수학숲 파티: 두 격리 브라우저가 같은 문제·진행·채팅 말풍선을 공유하고, 저장 실패 후 새로고침해도 보상은 한 번만 지급(v26 `partyClaims`).
- 자동 만남: 같은 학년·숲·단계는 「함께하는 수학숲 · 2명」, 다른 학년·다른 단계는 1명. 파티 시작 후에도 친구 아바타가 중복·사라짐 없이 1개.
- 명예의 전당: 연태쌤 대화(PC E·모바일 대화 버튼)로 진입, 레벨/베리 두 탭, 내 순위, 같은 캐릭터 한 줄만 표시.
- 서버 장애: `/hall` 503 응답 시 「기록 서버에 연결하지 못했어요」 안내 후 저장 상태 유지, 복구 뒤 새로고침으로 내 순위 표시.
- 전체 회귀(본판): 77개 통과, 1개는 데스크톱에서 의도적으로 건너뛰는 터치 전용 검사. 단독 실행 때 사냥 첫 화면 로딩이 5초를 넘긴 1회 지연이 있었고, 재실행에서 통과.
- 제작 빌드: 본판·앱 모두 통과.
