# 전투 연출 작업 기록

작업 브랜치: `visual/combat`. 게임 규칙·피해·보상·문제·저장 및 보호 테스트는 변경하지 않는다.

## 조사한 연결 구조

- `src/academy.ts`: `ACADEMY_SKILLS`의 48개 스킬 정의. 공통 3개, 기사·마법사·궁수 각 9개, 정령술사·연금술사 각 6개, 음유시인 6개.
- `src/skill-art.ts`: 새벽서약 그림 24개를 고정 ID로 아틀라스에 연결. `docs/dawn-skill-art.md`의 새싹·달·꽃·나무·약병·왕관·행성·음표 주제를 연출에 반영했다.
- `src/career-ui.ts`: `renderSkillIcon`, `renderCombatHud`가 아이콘과 네 스킬 칸을 표시. `src/career-controller.ts`의 `configure`, `startTraining`, 스킬 사용 처리가 직업·수련·저장과 월드를 연결한다. 두 파일은 유지했다.
- `src/hunting.ts`: `HuntingRuntime.attack/cast/step`이 명중·시전·처치 이벤트와 스냅숏을 만든다. 변경하지 않았다.
- `src/world.ts`: `huntAttack`, `useHuntSkill`, `handleHuntEvents`가 전투 입력과 연출을 연결하고 `frame`에서 카메라·플레이어·몬스터를 갱신한다. 일반 숲 몬스터는 `makeMonster`, 사냥터·수련·세계 2는 `HuntingWorld`로 만든다. `setWeather`의 기존 날씨 파티클과 품질 설정은 유지했다.
- `src/hunting-world.ts`: `enemy`, `makeEffect`, `animateEffect`, `onEvent`, `update`가 몬스터·스킬·명중·데미지 숫자를 표시한다.
- `src/world-two*.ts`: 지역·보스 진행, 장비와 행성 지형을 담당한다. 보스의 기존 나무·성운룡 윤곽은 유지하고 전투 어댑터에서 표정·오라·등장 자세를 보강했다.
- `src/legendary-pet.ts`: 펫과 오라의 전용 애니메이션·자원 해제. 전투 장식과 자원을 공유하거나 변경하지 않았다.

## 새 연출 모듈

- `src/combat-art.ts`: 48개 스킬 각각의 색·문양·대칭 수·회전 설정. 검·묵직한 무기·찌르기·활·마법·던지기·음악의 예비 동작 → 발동 → 잔상 → 복귀 키프레임.
- `src/combat-vfx.ts`: 시전 → 발사 → 명중 → 여운 타임라인. 셰이더 마법진·검 궤적·충격파·기둥과 가산 혼합 인스턴스 파티클. 프레임마다 새 메시를 만들지 않는다.
- `src/combat-monsters.ts`: 새싹·버섯·토끼·도토리·벌·여우 계열·구름·별 문양의 9개 윤곽. 큰 눈과 하이라이트, 배색, 그림자, 숨쉬기·걷기·예고·피격 찌그러짐·시각 넉백. 사냥터 처치 시 짧게 축소되며 빛 조각을 남긴다.

일반 화면은 동시 큐 18개·파티클 240개, 가벼운 화면은 큐 8개·파티클 64개 이하다. 단일 인스턴스 파티클 배치와 공유 지오메트리를 사용하며, 큐·투사체·타격·데미지 숫자를 재사용한다. 지역을 떠날 때 풀의 재질·지오메트리·텍스처를 해제한다. 전체 화면 후처리나 추가 동적 조명은 사용하지 않는다.

움직임 줄이기는 실행 중 시스템 설정 변경에도 반응한다. 흔들림·피격 플래시·파티클·상승 기둥과 회전 궤적을 끄고 고정 문양을 남긴다. 공격 자세의 움직임 폭도 줄인다. 히트스톱과 넉백은 모델에만 적용하며 전투 계산 시간이나 실제 좌표를 멈추거나 바꾸지 않는다.

현재 전투 규칙에는 치명타 판정이 없다. 시각 어댑터는 `critical: true` 명중 신호의 별도 색·크기·문자를 지원하지만, 치명타 확률이나 피해량을 새로 만들지 않았다.

## 확인과 이미지

`scripts/capture-combat.mjs`는 시스템 Chrome의 격리된 브라우저 기록을 사용한다. 외부 HTTP 요청을 막고 같은 좌표에서 기본 공격, 초승달 베기·태양의 서약·우주의 탄생·영원의 개화·별바다 교향곡 및 사냥터 3개 구역을 촬영한다.

- 변경 전: `screenshots/combat/before/`
- 변경 후: `screenshots/combat/after/`
- 추가 브라우저 검사: `e2e/combat-visuals.spec.mjs`에서 모든 직업의 스킬 셰이더, 실시간 움직임 줄이기, 일시정지를 확인한다.

저사양 실물 크롬북·태블릿의 60fps 달성 여부는 별도 기기 측정이 필요하다. 소프트웨어 WebGL Chrome 검사는 실제 기기 성능의 근거로 사용하지 않는다.

최종 검사: 타입 검사 통과, 단위 테스트 488개 통과, 전체 빌드 통과, 공용 소스 372개 및 generation 검사 통과. 시스템 Chrome E2E는 기존 데스크톱 사냥·새벽서약 9개, 추가 데스크톱·모바일 화면 및 터치 공격 3개가 통과했다. PC의 터치 전용 검사는 건너뛰고 모바일에서 확인했다. 브라우저 검사는 운영 서버와 분리된 로컬 서버에서 수행했다. 빌드의 기존 청크 크기·동적 import 경고는 남아 있다.

`screenshots/combat/comparison.html`에서 전후 슬라이더로 비교한다. 추가로 가벼운 화면·움직임 줄이기·치명타 표시 신호 예시와 직업별 모바일 화면을 `after/`에 넣었다. 치명타 예시는 시각 어댑터에만 신호를 주입한 화면이며 실제 게임 규칙에 치명타를 추가한 것이 아니다.
