# 베리숲 모험학교

베리를 모으고 숲을 탐험하며 **초등학교 1~6학년 수학**을 배우는 포근한 3D 학습 RPG입니다. 2022 개정 교육과정의 학년별 흐름을 바탕으로, 계산뿐 아니라 도형·측정·분수·소수·자료 영역을 각각의 모험 지역과 문제 그림으로 구성했습니다.

## 한눈에 보기

- 시작할 때 **1~6학년** 중 하나를 선택합니다.
- 각 학년의 1·2학기 수학 단원을 독립된 모험 지역으로 만납니다.
- 모든 수학 지역은 **10단계**로 구성되며 뒤로 갈수록 문제가 어려워집니다.
- 계산식, 이야기, 그림, 선택형 문제를 함께 사용합니다.
- 오답이나 대련 중단에 벌점이 없고, 그림과 단계별 힌트를 보며 다시 풀 수 있습니다.
- 진행 상황·오답·장비·방 꾸미기·도감은 현재 브라우저에 자동 저장됩니다.
- 단원별 학습 리포트와 문제 읽어주기 기능을 제공합니다.

## 수학 모험

학년마다 2022 개정 교육과정에 맞는 수와 연산, 변화와 관계, 도형과 측정, 자료와 가능성 영역을 다룹니다. 1학년의 수와 모양부터 6학년의 분수·소수의 나눗셈, 비례식, 원의 넓이까지 문제 범위와 풀이 그림이 학년에 맞게 달라집니다.

- **네 가지 계산 숲:** 덧셈·뺄셈·곱셈·나눗셈을 학년별 범위로 연습합니다.
- **단원별 수학 지역:** 평면도형, 길이와 시간, 분수와 소수, 원, 삼각형, 들이와 무게, 그림그래프 등을 학년별로 제공합니다.
- **자동 난이도:** 선택하면 연속 정답과 오답에 따라 계산 문제가 쉬움·보통·어려움 사이에서 조절됩니다.
- **그림자 몬스터:** 틀린 개념이 마을에 복습 몬스터로 나타나 같은 개념에 다시 도전할 수 있습니다.
- **별빛 재탐험:** 10개 사냥터를 통과한 뒤 기존 숲에서 새로운 목표와 이야기 문제를 이어서 해결합니다.
- **졸업·복습 모험:** 여러 단원을 섞어 다시 만나며, 빠르게 진도를 마친 학생도 계속 탐험할 수 있습니다.

## 탐험과 꾸미기

- 베리 수집, 몬스터 대련, 나무 베기, 레벨업과 장비 강화를 지원합니다.
- 현재 아이템은 **무기 18종, 의상 21벌, 라이딩 14종, 펫 15종, 시간제 물약 6종**입니다.
- 펫은 주변 베리까지 직접 이동해 먹으며, 일부 펫은 날개를 움직이며 날아다닙니다.
- 라이딩 중 별빛 페가수스 등 비행형은 물과 낮은 장애물 위를 지나갑니다.
- 헤어스타일과 얼굴을 바꾸고, 보유 가구를 원하는 칸으로 옮겨 나의 방을 꾸밀 수 있습니다.
- 일일 임무, 칭호, 도감, 정원, 개인 최고 기록과 전체 재탐험 랭킹을 제공합니다.

## 수업에서 활용하기

1. 교실 화면으로 게임을 열어 조작 방법을 3~5분 정도 안내합니다.
2. 학생은 개인 기기에서 학년과 수학 지역을 선택해 10~20분 동안 도전합니다.
3. 활동 뒤에는 도감의 학습 리포트에서 잘 이해한 단원과 다시 연습할 개념을 확인합니다.

설정의 교사용 시연 기능을 사용하면 모든 지역과 아이템을 바로 보여 줄 수 있고, 오늘 학습할 단원·난이도·플레이 시간을 정할 수 있습니다. 이 기능은 수업 시연을 위한 브라우저 내부 편의 기능이며, 별도의 로그인이나 서버 인증 기능은 아닙니다.

## 조작 방법

| 환경 | 조작 |
|---|---|
| PC | `WASD`/방향키 이동, `Space` 점프, `E` 대화, `F` 무기 휘두르기 |
| 태블릿·스마트폰 | 화면 조이스틱과 대화·휘두르기·점프 버튼 |
| 문제 풀기 | 키보드 숫자·`Enter` 또는 화면 숫자판 |

휴대폰과 성능이 낮은 태블릿에서는 설정의 **가벼운 화면**을 켜 그림자와 효과 부담을 줄일 수 있습니다.

## 저장·개인정보·온라인 기능

- 저장 키는 `berry-forest-save-v1`이며 저장 파일 형식은 현재 version 14입니다.
- 닉네임, 캐릭터, 학년별 진도, 장비, 베리, 레벨, 위치와 설정을 브라우저에 저장합니다.
- 설정에서 저장 파일을 JSON으로 내보내거나 다시 불러올 수 있습니다.
- 로그인, 채팅, 광고와 결제 기능은 없습니다.
- 전체 랭킹에는 닉네임과 별빛 재탐험 최고 기록만 전송합니다. 학생에게는 실명 대신 별명을 사용하도록 안내해 주세요.
- 우리 반 협동 보스는 반 코드·익명 기기 번호·주간 정답 수만 사용합니다.
- 한 번 접속한 뒤에는 서비스 워커가 필요한 파일을 보관해 인터넷이 불안정한 상황을 돕습니다.

## 로컬 실행

Node.js 22 이상과 pnpm이 필요합니다.

```sh
pnpm install
pnpm dev
```

`index.html`을 직접 더블클릭하지 말고 개발 서버가 표시하는 HTTP 주소로 접속해 주세요.

## 검사와 제작

```sh
pnpm exec tsc --noEmit
pnpm test
pnpm build
```

제작된 정적 웹 파일은 `dist` 폴더에 생성됩니다. `main` 브랜치에 푸시하면 GitHub Actions가 타입 검사·테스트·빌드를 거쳐 GitHub Pages에 배포합니다.

랭킹과 우리 반 협동 보스 API는 `worker/index.js`에 있습니다. 협동 보스를 새 서버에 배포할 때는 `drizzle/0001_*.sql`의 `boss_progress` 테이블도 함께 적용해야 합니다.

## 주요 구조

- `src/rules.ts`: 아이템·몬스터·보상·강화·저장과 계산 대련 규칙
- `src/curriculum.ts`, `src/grade-content.ts`, `src/grade-*.ts`: 1~6학년 단원·문제·힌트 생성
- `src/curriculum-visual.ts`: 시계·자·도형·분수 등 문제 그림
- `src/villages.ts`, `src/world.ts`: 지역별 3D 마을, 탐험, 충돌과 캐릭터 모델
- `src/main.ts`: 시작 화면, 모험 지도, 대련, 상점, 인벤토리와 설정
- `src/report.ts`, `src/speech.ts`, `src/backup.ts`: 학습 리포트, 읽어주기와 저장 백업
- `worker/index.js`, `drizzle/`: 랭킹·협동 보스 서버와 데이터베이스 마이그레이션
- `tests/`: 문제 품질, 교육과정 범위, 저장·보상과 전체 플레이 흐름 검증
