# 베리숲 모험학교

초등학교 3학년 1·2학기 수학 전체를 탐험하는 3D 학습 RPG. TypeScript · Three.js · Vite.

## 이용 범위

- 공식 게임 링크를 학생·보호자·다른 선생님에게 공유하고, 비영리 수업과 가정에서 직접 플레이하는 것은 허용됩니다.
- 소스 코드, 문제·문구, 그래픽, 음악을 사전 서면 허락 없이 복사·수정·재배포·재호스팅하거나 상업적으로 이용하는 것은 금지됩니다.
- 저작권 표시를 제거하거나 자신의 작품처럼 표시할 수 없습니다.
- Three.js 등 외부 오픈소스 구성 요소는 각각의 라이선스를 따릅니다.

## 실행

Node.js 22 이상과 pnpm을 설치한 뒤 이 폴더에서 실행합니다.

```sh
pnpm install
pnpm dev
```

개발 주소는 실행 결과에 표시됩니다. 배포용 파일은 `pnpm build`로 생성되는 `dist` 폴더입니다. 서버 없는 정적 웹 호스팅으로 배포할 수 있습니다. `index.html`을 직접 더블클릭하는 대신 HTTP 서버에서 열어 주세요.

```sh
pnpm test
pnpm build
```

## 조작과 저장

- PC: WASD/방향키 이동, Space 점프, E 대화, F 무기 휘두르기. 문제는 숫자 키와 Enter 또는 화면 숫자판으로 풉니다.
- 태블릿: 왼쪽 조이스틱, 오른쪽 대화·휘두르기·점프 버튼. 설정의 ‘가벼운 화면’에서 그림자를 끌 수 있습니다.
- 가까운 베리나무를 여러 번 때리면 2~4베리가 나옵니다. 좋은 무기와 강화 단계일수록 필요한 타격 수가 줄어듭니다.
- 상점에는 12종의 무기와 16벌의 의상이 있으며, 🎒 인벤토리에서 보유 장비를 확인하고 바로 바꿀 수 있습니다.
- 나현이의 라이딩 상점에는 1,000~10,000베리의 라이딩 8종이 있습니다. 5,000베리 이상의 라이딩은 물과 낮은 장애물 위를 날 수 있습니다.
- 마을과 10개 사냥터의 베리·몬스터·나무는 한 번 획득하면 다시 생기지 않습니다. 다음 사냥터를 탐험해야 더 많은 보상을 얻습니다.
- 수학 모험의 문에서 1학기(덧셈·뺄셈, 평면도형, 나눗셈, 곱셈, 길이와 시간, 분수와 소수)와 2학기(곱셈, 나눗셈, 원, 분수, 들이와 무게, 그림그래프)를 고릅니다. 모든 지역은 10단계 지도이며 진행 기록은 지역별로 저장됩니다.
- 10개 사냥터를 모두 통과하면 별빛 재탐험이 열립니다. 기존 숲에서 표식 3개, 대련 2번, 이야기 문제 1개를 풀며 계속 새 원정을 시작할 수 있습니다. 반복 원정에는 베리·경험치가 재지급되지 않고 완수 기록과 칭호가 남습니다.
- 무기는 몬스터 보상·대련 점수·나무 베기에, 의상은 베리·경험치·스테이지 완료 보너스에 영향을 줍니다.
- 선생님은 설정의 교사용 코드를 입력해 수업 시연 모드(100만 베리, 모든 아이템과 전체 스테이지, 수업 단원·범위 설정)를 열 수 있습니다. 코드는 저장소에 평문으로 두지 않고 SHA-256 해시(`TEACHER_CODE_HASH`, `src/rules.ts`)만 둡니다. 코드를 바꾸려면 새 코드의 해시(`node -e "console.log(require('crypto').createHash('sha256').update('새코드').digest('hex'))"`)로 교체해 다시 배포하세요. 모두 클라이언트에서 동작하므로 저장 파일(JSON)을 직접 고치는 것까지 막을 수는 없습니다.
- 오답·대련 중단에 손실이 없습니다. 몬스터를 물리친 보상과 레벨업은 바로 저장됩니다.
- 저장 키는 `berry-forest-save-v1`입니다. **기기·브라우저·사이트 주소마다 별도 저장**되므로, 주소를 바꾸거나 브라우저 데이터를 지우기 전에 설정에서 JSON 파일을 내려받아 주세요.
- 저장 파일은 닉네임, 캐릭터, 장비, 강화, 베리, 레벨, 경험치, 위치, 최고 점수와 환경설정을 포함합니다. 서버로 업로드하지 않습니다.
- 로그인, 채팅, 광고, 결제는 없습니다. 전체 랭킹을 열면 닉네임과 별빛 재탐험 완주 횟수만 서버로 전송됩니다. 서버는 한 번에 오를 수 있는 횟수에 상한을 두고(처음 30회, 이후 기록 갱신 시 +3과 시간당 +6), 부적절한 닉네임을 받지 않으며, 같은 주소에서 1분에 10번까지만 기록을 받습니다. 랭킹 서버를 옮길 때는 빌드 환경변수 `VITE_RANKING_API`에 새 주소를 지정하고 `worker/index.js`의 `allowedOrigins`에 게임 주소를 넣으세요.
- 한 번 열어 본 뒤에는 서비스 워커(`public/sw.js`)가 파일을 캐시해 인터넷이 불안정해도 열립니다. 화면은 항상 최신 버전을 먼저 확인하고, 홈 화면에 설치할 수도 있습니다(`public/manifest.webmanifest`). 저장 파일을 7일 넘게 내려받지 않으면 하루 한 번 백업 안내가 나옵니다. 그래픽과 짧은 합성 음악은 게임 내에서 생성합니다.

- **그림자 몬스터(복습)**: 모험 중 틀린 개념마다 마을에 어두운 몬스터가 최대 3마리 나타납니다. 다가가 E(또는 대련 버튼)를 눌러 같은 개념을 다시 풀면 사라지고 🍓 15베리를 받습니다. 틀린 개념 목록은 기존 `curriculum.wrongSkills`를 그대로 쓰므로 저장 파일 구조는 바뀌지 않습니다.
- **학습 리포트**: 도감(📖) → 「학습 리포트 보기·인쇄」에서 단원별 정답률, 잘한 단원, 더 연습할 단원, 다시 만날 개념을 한 장으로 보고 인쇄할 수 있습니다. 이 기기의 기록으로만 만들며 서버로 보내지 않습니다.
- **문제 읽어주기**: 단원 문제 화면의 🔊 버튼(또는 설정의 자동 읽기)으로 브라우저 기본 음성(ko-KR)이 문제와 보기를 읽어 줍니다. 기기에 한국어 음성이 없으면 버튼이 나타나지 않을 수 있습니다.
- **우리 반 협동 보스**: 같은 반 코드를 쓰는 친구들의 정답 수가 이번 주 보스 체력을 함께 깎습니다(체력 = 200 + 100 × 참여 친구 수, 매주 월요일 초기화). 서버에는 반 코드·기기 번호·정답 수만 보냅니다. **새 DB 테이블이 필요합니다**: 랭킹 서버를 배포할 때 `drizzle/0001_*.sql`(`boss_progress`)이 적용되어야 하며, 적용되기 전에는 게임에 "서버가 아직 준비되지 않았어요"라고 표시되고 정답 수는 이 기기에 계속 모입니다.

- **계산 대련 자동 조절(선택 사항)**: 대련 준비 화면(또는 설정)의 난이도에서 「✨ 자동」을 고르면, 연속 3번 처음에 맞히면 한 단계 어려워지고 연속 2번 처음에 틀리면 한 단계 쉬워집니다(쉬움·보통·어려움 범위 안에서). 기본은 꺼져 있어 기존 동작은 그대로이고, 저장 파일은 바뀌지 않습니다(켜짐 여부만 이 브라우저에 기억).

## 구현 구조

- `src/rules.ts`: 아이템·몬스터 데이터, 문제 생성, 보상, 강화 및 저장 검증.
- `src/curriculum.ts`: 3학년 수학 지역별 10단계 임무와 문제·힌트 생성.
- `src/curriculum-visual.ts`: 평면도형, 길이·시간, 분수·소수 등 문제 그림.
- `src/villages.ts`: 각 수학 지역의 3D 마을 색과 장식 테마.
- `src/expedition.ts`: 반복 원정의 목표·칭호·진행 규칙.
- `src/world.ts`: 3D 월드, 충돌·점프·수집·복귀, 캐릭터와 몬스터 모델.
- `src/main.ts`: 시작·대련·상점·설정 화면, 입력, 저장·내보내기·불러오기.
- `src/audio.ts`: 사용자 시작 후 재생하는 배경음과 효과음.
- `tests/rules.test.ts`: 전체 출제 범위, 장비별 보상, 중복 정답 방지, 경제와 저장 검증.
- `tests/expedition.test.ts`: 해금·반복 목표·칭호·저장 이전·중복 보상 검증.

선택적으로 지원되는 브라우저에는 `read_adventure_status`, `open_adventure_settings` WebMCP 도구를 등록합니다. 미지원 브라우저에서도 게임은 동일하게 동작합니다.
